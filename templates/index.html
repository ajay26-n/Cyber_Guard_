CYBERGUARD BROWSER EXTENSION

Protect every tab in real-time. The CyberGuard extension automatically inspects site telemetry as you browse and blocks high-risk phishing threats instantly.

DOWNLOAD EXTENSION PACKAGE (.ZIP)
How to Install (Chrome / Edge / Brave):
  1. Open browser to chrome://extensions or edge://extensions
  2. Toggle Developer Mode (top-right corner).
  3. Click Load Unpacked (top-left).
  4. Select the Cyber_Guard_/extension folder in your project directory.
How to Install (Firefox):
  1. Open Firefox to about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on...
  3. Select extension/manifest.json
